# Relay Zones

Five-stage Hemi side runner. The run reads the public Hemi mainnet block when you press start (chain 43111, `https://rpc.hemi.network/rpc`). An even block plants a Shard behind the gate. An odd block plants a Hex. The page’s score comes from that same block. The wallet button can switch to Hemi mainnet. It does not sign or send.

Space jumps. E attacks. Hold Q to guard. The mouse wheel cycles weapons. F confirms the relay. I opens armor.
