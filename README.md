# Relay Zones

Five-stage Hemi side runner. The run reads the public Hemi mainnet block when you press start (chain 43111, `https://rpc.hemi.network/rpc`). An even block plants a Shard behind the gate. An odd block plants a Hex. The page’s score comes from that same block. The wallet button can switch to Hemi mainnet. It does not sign or send. The high-score list ranks each Hemi wallet. The app stores those scores. Nothing is signed or sent. Losing all five marks costs 500 points. On Deep, Gale, and Crown, librarian acid that hits the ground stays for about three seconds.

Space jumps. Hold Ctrl, S, or Down to crouch. E attacks. Hold Q to guard. The mouse wheel cycles weapons. F confirms the relay. I opens armor.
